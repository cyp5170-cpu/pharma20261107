 💊 医薬品890品目 添付文書実務パッケージ
 GitHub Pages Webサイト化＆パスワード保護 完全公開ガイド
========================================================================

本パッケージは、GitHub Pages を利用して無料で全世界どこからでも
スマホやPCのブラウザからアクセスできるWebサイトとして公開可能です。
また、ご指定のパスワード【 377011 】による完全ログイン認証ガードが
あらかじめ組み込まれています。

------------------------------------------------------------------------
■ パスワード認証の仕組み（完全組み込み済み）
------------------------------------------------------------------------
・トップページ（index.html）にアクセスすると、ログイン画面が表示されます。
・パスワード【 377011 】を入力すると認証が通り、メインビューアが起動します。
・未ログインの状態で各マニュアルのURLを直接開いても、認証ガード（auth-guard.js）
  が作動し、即座にログイン画面へ強制リダイレクトされます。
・画面右上の「🔒 ログアウト」ボタンを押すと、セッションが破棄され再ロックされます。

------------------------------------------------------------------------
■ GitHub へのアップロード＆公開手順（簡単 4ステップ）
------------------------------------------------------------------------

【ステップ 1】GitHub で空のリポジトリを作成する
1. ブラウザで GitHub ( https://github.com/ ) にログインします。
2. 右上の「＋」アイコン ➔ 「New repository」をクリック。
3. Repository name に任意の名前を入力（例: pharma-890 ）。
4. 「Public」（または「Private」※Pages利用時はProプランまたはPublic推奨）を選択。
5. 「Add a README file」等のチェックは【すべて外したまま】にし、
   緑の「Create repository」ボタンを押します。
6. 作成後に表示されるリポジトリURLをコピーします。
   （例: https://github.com/your-username/pharma-890.git ）

【ステップ 2】パッケージフォルダから GitHub に push する
本フォルダ内の「GITHUB_PUSH.bat」をダブルクリックして起動します。
プロンプトが表示されたら、ステップ1でコピーしたリポジトリURLを貼り付けて Enter を押します。
自動的に git init、コミット、アップロード（push）が完了します。

※手動でコマンド実行する場合：
   cd /d "C:\Users\froze\OneDrive\デスクトップ\医薬品840品目_添付文書パッケージ"
   git init
   git add .
   git commit -m "Initial release with password auth"
   git branch -M main
   git remote add origin <あなたのリポジトリURL>
   git push -u origin main

【ステップ 3】GitHub Pages を有効化する（ワンクリック）
1. GitHub のリポジトリページを開き、上部タブの「Settings」をクリック。
2. 左メニューの「Pages」をクリック。
3. 「Build and deployment」の Source で「Deploy from a branch」を選択。
4. Branch で「main」を選択し、フォルダは「/ (root)」のまま「Save」をクリック。

【ステップ 4】公開完了！
数分待つと、同じ画面に公開URLが表示されます：
👉 https://<あなたのGitHubユーザー名>.github.io/pharma-890/

アクセスするとパスワード入力画面が表示され、
【 377011 】を入力することで、PCでもスマホでもアプリとしてフル稼働します！

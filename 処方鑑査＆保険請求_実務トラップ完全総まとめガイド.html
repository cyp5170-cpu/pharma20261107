⏰ 【第2章】厳格服用タイミング（起床時・食直前・食直後）＆用法不備査定防止
用法不一致査定ワースト
服用タイミングと審査足切りルール 「食後」処方は査定！
医師が漫然と「毎食後」で切った処方箋をそのまま請求すると100%返戻
用法該当薬剤医学的理由と審査判定
起床時すぐ
(水約180mL)		 ボナロン / フォサマック / アクトネル (BP薬) 食後服用だと食物中のカルシウムと結合し吸収率ゼロ。服用後30分横臥禁止（逆流性食道潰瘍防止）。「毎食後」処方は疑義照会必須。
食直前
(食事開始10分以内)		 ベイスン / グルコバイ / セイブル (α-GI)
シュアポスト / ファスティック (速効型)		 二糖類分解酵素阻害のため、食後服用では血糖降下作用なし。速効型分泌薬は食後服用で遅発性低血糖。処方箋が「毎食後」なら査定対象。
食直後 エパデール / ロトリガ 食事の脂質によってミセル化・吸収されるため、空腹時・食間服用ではバイオアベイラビリティが激減。
就寝直前 マイスリー / ハルシオン / ルネスタ 超短時間作用型睡眠薬。「就寝前（30分前）」だと入浴・歩行中にふらつき・転倒・一過性前向性健忘を起こすため「直前」指定。
🧴 【第3章】外用薬（湿布63枚・ステロイドランク・点眼本数・軟膏混合）
支払基金重点点検項目
湿布63枚制限＆点眼液本数計算 機械査定防止
1処方上限枚数と過剰本数の自動フラグ
  • 湿布薬63枚制限: 1処方につき原則63枚上限。超過時は理由（広範疼痛部位・頻回通院困難等）の症状詳記が必須。同一効能の湿布2種併用（腰にモーラス＋膝にロキソニン）は部位詳記なしで査定。
  • 点眼液の本数計算: 1本5mL＝約100滴。「両眼1日3回（計6滴/日）➜ 30日で180滴（約2本）」。30日処方で3本以上出すと過剰投与として全額査定。
ステロイドランク別部位＆軟膏混合 配合変化・審査
顔面強ランク処方の査定、エマルション破壊
ランク代表薬処方適応・部位制限
I群 Strongest / II群 Very Strong デルモベート / ダイアコート / マイザー / アンテベート 体幹・四肢・手足の苔癬化病変。顔面・頸部・陰部への処方は査定アラート（皮膚萎縮・緑内障）。
III群 Strong / IV群 Medium ボアラ / メサデルム / ロコイド / キンダベート 顔面・陰部・小児にはIV群（Medium）以下が原則。
軟膏混合の配合変化: ヒルドイドソフト（W/O型乳剤）に水性クリーム（O/W型）やステロイド軟膏を安易に混ぜると、乳化破壊（相分離・水滴遊離）や主薬力価低下を起こします。
🏷️ 【第4章】長期収載品の選定療養（患者希望自己負担）＆医療上必要性
2024年〜2026年最新制度
選定療養の仕組みと「医療上必要性」 保険給付判定
後発医薬品がある先発品を希望した場合の特別料金（差額の1/4自己負担）

【医療上必要性が認められる正当理由（選定療養除外・保険給付のまま交付）】
① 後発品で過去にアレルギー・重篤な副作用・効果不十分の治療歴がある場合
② 後発品に存在しない剤形（錠剤・シロップ・粉砕対応等）が必要な場合
③ 嚥下困難で先発品（単剤・特定コーティング）でなければ服用困難な場合
④ 後発医薬品の限定出荷・供給停止に伴い先発品を使用せざるを得ない場合

📋 医療上必要性のレセプト症状詳記文例
【症状詳記】過去に後発医薬品（〇〇錠）への変更時に薬疹（アレルギー反応）の既往があるため、医学的観点から先発医薬品（〇〇錠）の継続投与が不可欠であり、医療上必要性があると判断し保険給付にて処方した。

🌿 【第6章】漢方製剤（保険病名不一致・甘草合算・偽アルドステロン症）
安全性＆査定
甘草重複合算＆保険病名チェック 低K血症・偽アルドステロン症
漢方薬併用時の甘草1日2.5g〜5g超過リスク
  • 甘草合算リスク: 漢方薬を2剤以上併用すると甘草総量が急増。11β-HSD2が阻害され、低カリウム血症、激しい浮腫、高血圧、四肢脱力（偽アルドステロン症）を誘発。
  • 芍薬甘草湯の連用査定: こむら返りの頓用は通るが、漫然と定期連用すると支払基金の重点点検で査定。
  • 葛根湯: 感冒・肩こりは通るが「腰痛症」では適応外査定。
  • 防風通聖散: 単なる肥満では査定。「肥満症」「高血圧随伴症状」病名が必須。
